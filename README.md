## 选国外云服务器，先看三个硬指标

判断一台国外云服务器值不值得买，看计费方式、机房位置与线路、支付和售后门槛这三样就够了，入门配置反而是最不用担心的部分。

**计费方式**决定试错成本。市面上大部分商家按月付、季付甚至年付收费：搬瓦工的入门方案 $50/季度起，Hostdare 的美国机房按年付 $50 起，价格确实便宜，但钱是先付的，业务只跑两周也得按整个周期算。按小时计费的商家（Vultr、LightNode）把这笔账变成变量，用多久扣多久，不用了删掉机器就停止计费。

**机房位置和线路**决定访问速度。面向海外用户，机房选在目标用户附近；主要给大陆访客用的话，普通国际线路晚高峰会有波动，得挑有大陆优化线路的商家，这也正是搬瓦工、DMIT 这类 CN2 GIA 商家的卖点。

**支付和售后门槛**最容易被忽略。DigitalOcean 是很多新手教程里的常客，但它不支持支付宝等国内支付方式，付款环节就劝退了一批人；Vultr、Hostwinds、搬瓦工都支持支付宝。另外境外机房不需要 ICP 备案，开通就能建站，这点和国内服务器完全不同。

## 常见问题

### 国外云服务器需要备案吗？

不需要。境外机房不受国内 ICP 备案要求约束，开通后解析域名就能建站，这也是很多人选国外服务器的直接原因。

### 按小时计费会不会算下来反而更贵？

不会。单机费用封顶为月价，用满一个月不会超过标价；用不满就只付实际时长。带宽流量超出套餐的部分可能另外计费，这是云服务商通行的规则。

### 服务器在国外，国内用户访问会慢吗？

看机房和线路。选址合理、线路有优化的话影响不大；面向大陆访客的站点，直接选大陆优化线路的商家更稳妥。

### Vultr 能装 Windows 吗？

能。Vultr 提供 Windows 系统镜像，和 Linux 一样按小时计费。

### 云服务器的费用一般包含哪些部分？

计算资源、存储、带宽三块，各家定价策略不同。下单前把这三项的单价看全，才能算出真实月账单。
